AI 工具箱隐私说明

最后更新：2026-11-12

AI 工具箱是一款自带 API Key 的文本处理扩展。本说明解释扩展会保存哪些信息、何时联网，以及你可以如何删除这些信息。

1. 本地保存的信息

  • DashScope API Key：保存在浏览器的 chrome.storage.local 中，用于调用你选择的模型服务。开发者不会收到该 Key。
  • 偏好设置：模型名称、翻译目标语言保存在本地。
  • 最近一次处理结果：仅保存在 chrome.storage.session 会话存储中，浏览器完全退出后会清除。

2. 何时联网

只有在你主动点击“开始处理”或通过右键菜单处理选中文本时，扩展才会把以下内容通过 HTTPS 发送到阿里云 DashScope：

  • 你输入的或选中的待处理文本；
  • 处理类型对应的提示词；
  • 你选择的模型名称和翻译目标语言。

模型服务的请求处理和数据处理规则受阿里云 DashScope 的隐私政策与服务条款约束。

3. 网页读取

“读取当前网页”功能只在你主动点击按钮时执行；右键菜单只读取你主动选中的文字。扩展不会在后台持续记录浏览历史，也不会自动上传网页内容。

4. 扩展不会收集的信息

  • 不会收集浏览历史、搜索记录或账号密码；
  • 不会建立开发者服务器，不包含统计、广告或用户画像 SDK；
  • 不会向第三方出售或共享数据。

5. 数据删除

你可以在扩展设置中清除 API Key，或在 Edge 的扩展管理页面移除扩展。移除扩展会删除扩展保存的本地数据，但不会影响你在 DashScope 平台上的账户与账单记录。

6. 权限用途

  • storage：保存 API Key、模型偏好和会话结果。
  • contextMenus：提供划词右键菜单。
  • activeTab：在你主动操作扩展时读取当前标签页。
  • scripting：提取当前网页正文，不注入远程代码。

7. 安全提示

请使用自己的 API Key，不要在共享电脑上保存敏感 Key。若 Key 可能泄露，请立即到 DashScope 控制台撤销并重新生成。

8. 联系方式

如对隐私处理有疑问，请通过 Edge 加载项商店页面提供的开发者联系方式咨询。

# AI 工具箱（Edge 扩展）

一个基于 Manifest V3 的轻量 Edge 扩展，提供摘要、翻译、润色、校对、回复、JSON 抽取、测验、FAQ、代码解释和报错诊断 10 项 AI 工具。扩展直接调用阿里云 DashScope 的通义千问兼容接口，不需要自建后端。

## 功能

- 摘要：把长文总结成 3-5 个要点。
- 翻译：支持中文、英语、日语、韩语、法语、德语和西班牙语。
- 润色：支持正式专业、活泼口语、简洁干练、营销文案、学术严谨 5 种风格。
- 校对：检查错别字、语法、标点和不通顺表达，并给出问题清单与完整修正版。
- 回复：支持礼貌正式、友好亲切、简洁直接、委婉拒绝 4 种语气。
- JSON 抽取：从文本中提取结构化信息并格式化 JSON。
- 测验：根据学习内容生成 3 道单选题和 2 道简答题，附答案解析。
- FAQ：根据产品或服务介绍生成 5 个常见问题与解答。
- 代码解释：说明代码功能、核心逻辑和关键步骤，并提示明显问题。
- 报错诊断：根据报错、堆栈和代码片段定位根因，给出排查步骤和修正建议。
- 划词右键菜单：选中文字后直接选择处理方式，弹窗自动填入并执行。
- 网页正文读取：一键提取当前网页正文或页面中选中的文字。
- 请求控制：90 秒超时、支持停止请求、清晰的 HTTP 错误提示。
- 后台请求：模型请求由 Service Worker 发起，最近结果保存在会话存储中，重新打开弹窗时可恢复。
- 隐私清理：切换功能标签或点击“清空内容”会清除输入、输出、来源信息和会话中的最近结果。
- 深浅色主题：跟随系统颜色模式。

## 安装

1. 打开 Edge，进入 `edge://extensions/`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本仓库目录。
4. 点击扩展图标，填写 DashScope API Key，选择模型并保存。

API Key 可在阿里云 DashScope 控制台创建。该扩展采用 BYOK（Bring Your Own Key）模式，Key 仅保存在当前浏览器配置中。

## 使用

- 普通流程：点击扩展图标，选择功能，粘贴文本，点击“开始处理”或按 `Ctrl + Enter`。
- 网页流程：点击“读取当前网页”，扩展会优先使用页面中选中的文字，否则提取正文。
- 划词流程：在网页中选中文字，右键打开“AI 工具箱”，选择摘要、翻译、润色或 JSON。
- 翻译流程：切换到“翻译”标签后，可在“翻译目标语言”中选择目标语言。
- 润色流程：切换到“润色”标签后，可在“润色风格”中选择正式专业、活泼口语、简洁干练、营销文案或学术严谨。
- 回复流程：切换到“回复”标签后，可选择礼貌正式、友好亲切、简洁直接或委婉拒绝。
- 开发流程：切换到“代码”解释选中代码；切换到“报错”粘贴错误日志、堆栈和相关代码。
- 清理流程：点击“清空内容”会清空当前工作区；切换到其他功能标签时也会自动清理，避免不同任务的数据混在一起。

## 权限说明

- `storage`：保存 API Key、模型偏好和会话结果。
- `contextMenus`：创建划词右键菜单。
- `activeTab`：仅在用户主动操作扩展时访问当前标签页。
- `scripting`：读取当前网页正文。
- `https://dashscope.aliyuncs.com/*`：调用 DashScope 模型接口。

扩展没有申请 `<all_urls>`，不会在后台持续注入内容脚本。

## 已知限制

- 单次最多处理 50,000 个字符，超出部分会提示缩短或截断。
- 单次请求超时为 90 秒，不包含流式输出。
- `edge://`、扩展页面、应用商店等受保护页面不能读取正文。
- 读取本地 `file://` 页面时，需要在扩展详情中开启“允许访问文件 URL”。
- 网页正文提取是启发式规则，复杂页面可能需要手动复制文本。
- 公开发布时，用户输入会发送给模型服务商；请勿处理不允许上传的敏感内容。

## 开发与检查

要求 Node.js 20+，无第三方运行时依赖。

```powershell
npm run check
```

检查内容包括：Manifest 字段、被引用文件是否存在、图标尺寸是否正确、HTML 基本结构、JavaScript 语法。

生成 Edge 加载项商店用的 ZIP：

```powershell
npm run package
```

输出位于 `dist/ai-toolbox-extension-v<version>.zip`。

## 项目结构

```text
manifest.json       扩展清单
background.js       Service Worker、右键菜单、模型请求、网页正文提取
popup.html          扩展弹窗界面
popup.js            弹窗交互与后台消息
privacy.html        扩展内隐私说明
PRIVACY.md          隐私政策源稿
scripts/validate.mjs 静态检查
scripts/package.ps1 打包脚本
```

## 上架前检查

- 在 `edge://extensions/` 通过“加载解压缩的扩展”完整测试一次。
- 准备 16/32/48/128 图标、商店截图、简短描述和权限用途说明。
- 将 `PRIVACY.md` 部署到可公开访问的 URL，并在商店后台填写。
- 运行 `npm run package`，上传生成的 ZIP。
- 不要将共享服务端 Key 写入扩展；如需统一计费，应改为自己的后端代理并重新评估隐私与权限。
